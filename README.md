# 🏥 Medilab – ASP.NET Core Web Application with Dapper

Welcome to **Medilab**, a simple health service web project built using ASP.NET Core MVC.  
This project was created for educational purposes — mainly to practice **Dapper ORM** in a real-world scenario.  
Practicing by building projects is one of the best ways to learn, and this one helped me improve my skills in backend development.

---

## 📌 Overview

- The homepage is fully built using **Razor view components** for better structure and easier maintenance.
- Users can **book appointments** and **send contact messages** without reloading the page, using **AJAX + SweetAlert** for a smoother experience.
- I used a custom `ServiceRegistrations` extension class for all **service registration and dependency injection**.
- **Dapper** is used as the main ORM tool for handling database operations in a lightweight and efficient way.

---

## 🛠️ Technologies Used

- 🧩 ASP.NET Core MVC  
- 🛢️ Dapper  
- 🔄 AJAX  
- 💬 SweetAlert  
- 🧷 Dependency Injection  
- 🧱 Razor View Components
